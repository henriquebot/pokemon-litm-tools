# Pokémon LITM Tools

Módulo para Foundry VTT V14 voltado a campanhas Pokémon usando Legend in the Mist.

## Planejado

- Importador de Trainers
- Importador de Pokémon
- Tokens 2D animados
- Integração opcional 3D
- Catálogo de mapas 2D
- Pokémon Challenge Builder
- Trainer Class Challenges
- Journeys para rotas e localidades

Assets proprietários de Pokémon não são distribuídos neste repositório.
